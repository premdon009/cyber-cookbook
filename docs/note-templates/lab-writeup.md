# Lab write-up template

Use this for every box, room or exercise you finish. Writing the blue side of an offensive lab
is what turns this into purple-team practice.

````markdown
# <Lab / box name>

**Platform:** <OverTheWire / GOAD / Vulhub …> · **Date:** YYYY-MM-DD · **Level:** L? · **Time spent:** ?h

## Goal
What the lab asked you to do.

## Recon
What you found, and how (commands summarised, not dumped).

## Path to the goal
Numbered steps, each with:
- what you tried
- what worked and why
- ATT&CK technique

## What a defender would see
For each step: the event, log or artifact it produced, and whether your SIEM caught it.

## Fix
How the target should be hardened.

## Lessons / new recipes to write
- …
````
